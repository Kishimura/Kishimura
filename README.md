## Projeto em destaque

### CS3 Horímetro

Projeto em Python criado para resolver um problema real no meu ambiente de trabalho.

No processo de corte de mármore e granito, as máquinas utilizam horímetros para controlar o tempo de corte. Antes desse projeto, o cálculo era feito manualmente com anotações em papel e calculadora.

O projeto ajuda a calcular o tempo total de trabalho da máquina com base no horímetro inicial e final, reduzindo erros manuais e tornando o processo mais prático.

Tecnologias e conceitos utilizados:

* Python
* Funções
* Validação de dados
* Cálculo de tempo
* Listas e dicionários
* Git/GitHub
* Resolução de problema real
