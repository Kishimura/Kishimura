## Featured Project

### CS3 Horímetro

A Python project created to solve a real problem at my workplace.

In the marble and granite cutting process, machines use hour meters to track cutting time. Before this project, the calculation was done manually using paper notes and a calculator.

This project helps calculate the total machine working time based on the initial and final hour meter values, reducing manual errors and making the process more practical.
